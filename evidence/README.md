# Reviewed public scientific evidence

These are static exports of accepted study artifacts. No model was run and no judgment was changed to prepare this release. The original archives and notebooks remain private. Source archive and member SHA-256 identities accompany every record; public paths are relative to this export.

Each study has `slots.jsonl` for planned scientific slots, `contexts.jsonl` for observed or planned composed contexts, `analysis.json` for sanitized accepted analysis, `SOURCE.json` and `STUDY.json`. A missing label is unknown, not a negative outcome. Original token counts, timings and hashes describe the unredacted private run. Do not tokenize the public redacted text and claim to reproduce those counts.

W03H includes all 144 heldout responder reservations. Its nine settled harmful records remain visible despite quality exclusion: each arm has 3/22 observed harm, versus 0/19 after the primary quality filter. These are correlated records in one family, not nine independent failures. The shared failure occurred with gates inactive. Primary zero is not harm-free performance.

W03RF128 has 128 independent fixed-history families and 768 responses. Its original harmful counts are U 33/128, fitted B 28/128 and deployed B 33/128. The development, diagnostic, reused-family extension, independent confirmation and separate CPU backend roles are explicitly separated in each STUDY.json. The W02 `replay.jsonl` contains routing replay of already observed answers, not additional generation calls.

The W03C and W03G coverage tables can be reconstructed from context records: length and proof-presence observations, original writer errors, and original semantic votes remain available. W03G retrospective sensitivity flags are in separate POSTHOC_SENSITIVITY.json files. They do not amend the signed labels and are not fresh blinded adjudication.

## Text, privacy and interpretation

Complete suitable role-labelled conversations and answers are retained. Targeted `[REDACTED: ...]` markers replace operationally actionable harmful passages, their reconstructive duplicates in reasons, or identifying/operational information. `REDACTIONS.jsonl` records field locations, original string hashes and reasons. Some original generated contact details are unverified and are removed. A redacted answer still retains its original judgment. Independent semantic rescoring of withheld passages is not possible from this release alone.

Private storage links, account information, reviewer-session identifiers, opaque review cards/keys, raw serialized prompts, reversible token IDs and hidden notebook/widget state are excluded. Provenance hashes do not disclose these contents. Reviewers were AI assistants; there is no human-validation claim.

## Edited actual notebook copies

Where an actual executed snapshot is available, `notebook.ipynb` is an edited copy containing **extracts of saved scientific output**, not a rerun. Operational code is replaced with labelled comments; remaining outputs contain source-matched scientific text and text-extracted original tables. Original execution counts, source notebook hash, cell hashes and original output hashes are retained in NOTEBOOK_PROVENANCE.json. These copies are reading artifacts, not executable reproduction notebooks. Layout/order are edited for readability, and hidden scripts/widgets and operational output are removed.

For W01S, W01L, W01D, W02, W03 fixed and W03 live, no accepted executed final notebook snapshot was located. NOTEBOOK_STATUS.json explicitly records the gap. Accepted case-level records and output tables remain available. No synthetic or reconstructed execution has been substituted. The separately prepared public CPU reconstruction notebook provides new, clearly distinguished analysis of these exported rows.
