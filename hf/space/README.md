# Conversation safety steering · reviewed evidence viewer

Static research viewer by Muhammad Ariz Muhammad Akmal, with substantial AI assistance. No inference, GPU, account login or model download is required. Filter reviewed evidence by study, family, writer, branch and responder; inspect observed labels separately from primary eligibility. Necessary redactions are marked. All evaluation labels are assistant-only, not human validated.

The 128-family authored replication was negative; W03H retained shared harmful gate misses (3/22 observed versus 0/19 primary harm per responder). Filtered zero is not harm-free performance. Repeated histories and small curated cohorts limit generalization.
